# What this session did (2026-11-07)

The Habita Figma file now has a second page, **"Prototype"**. It holds clean copies of the approved screens, linked so you can click through them in Figma's Present mode.

- **Two starting points.** "Admin" starts at the admin Log in screen. "Audience" starts at Register.
- **What you can play.** Only the main path, where everything succeeds. Error and validation screens, mobile layouts and views that depend on permissions are left out on purpose.
- **What hasn't changed.** The spec page "BRD-standard-project-bootstrap" is exactly as it was.
- **Plain copies.** The screens on the Prototype page are copies. If a screen on the spec page changes, its copy has to be updated by hand; ask Claude to re-copy it.
- **One manual step.** Figma's automation can't set two dialog settings: the dimmed background and closing when you click outside. In Figma, select each "Admin / Dialog / …" frame, open the Prototype panel → Overlay settings, tick "Close when clicking outside" and set the background to 50% black.

The design, with every link listed, is in `prototype-design.md` in this folder.
